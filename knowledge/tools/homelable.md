Self-hosted homelab visualizer: interactive network diagram with live status, scanning and per-device docs.

## Key Features

- Network, Zigbee and Z-Wave scanning
- Ping/TCP/health-API checks for online/offline overview
- Customizable device layouts, PNG export
- Rack canvas, Proxmox integration, REST API and MCP server
- Documentation library for runbooks and incidents
