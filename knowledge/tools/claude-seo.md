Free MIT-licensed SEO audit plugin for Claude Code by Agrici Daniel (~20.5k stars). 26 sub-skills and 19 specialist sub-agents run in parallel.

## Key Features

- Technical SEO, Core Web Vitals, E-E-A-T, schema markup audits
- GEO/AEO for AI search, llms.txt, agent readiness (WebMCP, Lighthouse Agentic Browsing)
- Backlinks, local SEO, e-commerce, international (hreflang)
- Google API integrations; PDF/Excel reporting; 9 optional live-data extensions
