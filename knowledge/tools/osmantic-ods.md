ODS V3 pre-release turns a PC, Mac or Linux box into a private AI server. It detects hardware, downloads a suitable model, and starts local inference plus Open WebUI. Python, ~7.7k stars, Apache 2.0 plus a Pixel ODS-only clause.

## Key Features

- Hardware detection and best-fit model download
- Open WebUI front end and one dashboard for the whole stack
- Add-ons: voice (STT/TTS), agents (Hermes), n8n workflows, RAG, search, ComfyUI image generation
- NVIDIA, AMD and Strix Halo support; no cloud or subscription
