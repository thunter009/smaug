Agent-ergonomic CLI/skill (v0.1.27) that lets you iterate with a coding agent through interactive HTML artifacts instead of walls of text and markdown. Invoke as the `/lavish` skill or with a prompt like `/lavish let's discuss what options we have`.

## Key Features
- Installable and invocable as a skill (`/lavish`)
- Give feedback and edits to the agent via the HTML itself, not just by asking it to write HTML
- Recent fixes: more correct generated styling, more reliable polling
- Part of the AXI family (CLIs designed for agent ergonomics, token efficiency); siblings: chrome-devtools-axi, gh-axi
