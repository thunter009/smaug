Frontend stack for agents and generative UI, from the makers of the AG-UI Protocol. Lets agent-native apps render chat, tool calls, shared state and human-in-the-loop flows on React, Angular, Vue, React Native, Slack and Teams. About 38k stars at bookmark time (TypeScript, MIT).

## Key Features
- Chat UI: customizable, streams messages, tool calls and agent responses
- Backend tool rendering: agent tools return UI components rendered in the client
- Generative UI: agents create and update components at runtime from user intent and state
- Shared state: synchronized state layer that agents and UI both read and write
- Human-in-the-loop: agents pause to request input, confirmation or edits
- Rich threads and automatic learning via the paid CopilotKit Intelligence layer
- Any LLM, any agent framework, your own components and design system; AG-UI adopted by Google, LangChain, AWS, Microsoft, Mastra, PydanticAI
