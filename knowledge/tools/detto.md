Swift macOS app (Apple Silicon, macOS 26+, BSL 1.1) that captures meetings, voice memos and system-wide dictation fully locally, writing markdown with YAML frontmatter into an Obsidian vault (521 stars).

## Key Features

- Call capture: mic ("You") and system audio ("Them") with conferencing app detection (Teams, Zoom, Slack, Webex, Meet)
- ASR via Parakeet-TDT v3 on the Neural Engine; refinement via Llama 3.2 3B on MLX
- Hold-to-speak or toggle dictation injected at cursor in any app
- Reads client files pre-call to embed context and rename transcripts
- No server, account or analytics
