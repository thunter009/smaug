Terminal file explorer meant to sit as a pane beside coding agents (Claude, Codex). Shows what agents change across a codebase and gives quick path copying. Run with `bontree .`. GitHub API returned no README or description, so details come from the author's tweet only.

## Key Features

- Copy file paths quickly
- Live git status to watch agent changes
- Flat and hierarchical search
- Mouse support
- Theme support
- Responsive down to small widths
