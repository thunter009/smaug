# Agentfiles

Obsidian plugin to browse, create and manage AI agent skills, commands and agents across Claude Code, Cursor, Codex, Windsurf and more.

## Key Features

- Browse skills across 12+ coding tools from Obsidian
- Create and edit agent files in-vault
- TypeScript, 858 stars
