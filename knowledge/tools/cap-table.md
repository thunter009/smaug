Open-source (MIT) cap table worksheet and npm library (@1984vc/cap-table) from 1984 Ventures for modeling how financing rounds affect ownership. Designed as a tool for AI to call so cap table math is computed correctly rather than guessed.

## Key Features

- TypeScript library, Node 18+, npm package
- Models dilution across investments (SAFEs, rounds)
- Intended as a deterministic tool for LLM-driven cap table modeling
