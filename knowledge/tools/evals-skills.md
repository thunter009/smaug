Skills plugin by Hamel Husain and Shreya Shankar that guides coding agents through building product-specific AI evals (not foundation model benchmarks). Distilled from helping 50+ companies avoid common eval footguns.

## Key Features

- evals-start: entry point that inspects your situation and routes to the right skill
- error-discovery: agent builds a custom review app with intelligent trace sampling; groups annotations into failure modes and finds related examples
- eval-audit: audits an existing eval pipeline and surfaces problems by severity
- Install via `npx skills add https://github.com/ai-evals-course/evals-skills`
