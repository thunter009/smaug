Anthropic's public repository of Agent Skills (Python, ~184k stars): folders of instructions, scripts and resources Claude loads on demand. Includes the docx/pdf/pptx/xlsx document skills, a spec, a template, and the skill-creator skill that was recently updated.

## Key Features

- skill-creator skill for authoring new skills
- Document skills (docx, pdf, pptx, xlsx) as production references
- Installable as a Claude Code plugin marketplace: `/plugin marketplace add anthropics/skills`
- Skill = folder with SKILL.md (name + description frontmatter)
