Apple's `container` project documents "container machines": lightweight, persistent Linux environments on a Mac, with the user's home directory and repos automatically mounted. Announced at WWDC; Tim Sneath expects it to be a sleeper hit. (Repo content was not fetched; description is from the tweet.)

## Key Features
- Lightweight persistent Linux environment on macOS
- Home directory and repos mounted automatically
- Part of Apple's open-source `container` tooling
