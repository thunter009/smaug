Open Knowledge Format (OKF) is a vendor-neutral open spec from Google Cloud that formalizes the "LLM-wiki pattern" into a portable format. It lives in the GoogleCloudPlatform/knowledge-catalog repo (Apache 2.0, TypeScript, ~9.5k stars), alongside tools and samples for Google's Knowledge Catalog (formerly Dataplex).

## Key Features
- Just markdown: readable in any editor, renderable on GitHub, indexable by any search tool
- Just files: shippable as a tarball, hostable in any git repo, mountable on any filesystem
- Just YAML frontmatter: queryable fields type, title, description, resource, tags, timestamp
- Reference implementations: BigQuery enrichment agent, static HTML visualizer, sample bundles
- Knowledge Catalog can natively ingest OKF
