# DocSetQuery

Python tooling that lets agents build local Markdown documentation from Apple DocSet bundles, instead of web scraping.

## Key Features

- Local-first Apple documentation extraction, cleanup and search
- Deterministic lookup for agent workflows
- Brotli CLI support
