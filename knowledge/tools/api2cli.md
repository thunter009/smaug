Claude Code skill system by Alex Hillman. Tell Claude "build me a CLI for [any API]" and it generates a working CLI wrapper.

## Key Features

- Drop into a Claude Code setup as a skill/system
- Prompt-driven: one sentence yields a CLI for an arbitrary API
- Author reports no API has defeated it yet, though some are harder
