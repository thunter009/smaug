Kit that turns Claude (and Codex, Cursor, Copilot, Aider via MCP) into a "Senior Design Architect". Bundles design-system doctrine, DTCG design tokens, runnable skills, and objective gates that fail the build. ~3k stars, MIT, npm package `ux-ui-agent-skills`.

## Key Features

- 138 brand-grade design systems, 52 component specs
- 26 runnable skills, 14 DTCG token files, 16 framework adapters (React 19, Next.js 15, SwiftUI, any framework)
- 52 objective gates, 34 run in a real browser: WCAG contrast in every state, axe roles/landmarks, keyboard, target size, reduced motion, no horizontal overflow at 280px
- WCAG 2.2 AA to AAA targets
