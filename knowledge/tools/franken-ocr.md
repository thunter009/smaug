Memory-safe, pure-Rust OCR library and CLI (focr) by Jeffrey Emanuel, optimized for Apple Silicon and many-core CPUs with minimal dependencies. It wraps the Baidu OCR model for text and adds specialist models for sheet music (MusicXML), image captioning and chart-data extraction. It lets agents do bulk OCR cheaply and locally with no GPU instead of burning Claude Code or Codex tokens.

## Key Features
- Baidu OCR model for regular text; specialized converted models for music notation, captions, charts
- Runs locally on CPU, free and open source
- Companion agent skill at jeffreys-skills.md/skills/focr
