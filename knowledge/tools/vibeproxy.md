VibeProxy (automazeio) is a proxy that aggregates logins to many AI subscriptions (Claude Max, GPT Pro, Kimi, Copilot, Antigravity, Gemini, ZAI, local servers) behind one provider endpoint. Harnesses such as Droid, Codex, Parchi and Claude Code can point at it and use any model from any signed-in subscription without extra per-token cost.

## Key Features
- Single endpoint fronting multiple subscription logins
- Works with any harness that accepts a custom provider URL
- Uses existing flat-rate subscriptions instead of API billing
- Can include a home AI server as a backend
