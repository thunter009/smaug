Pi extension that brings the psst secrets manager into the pi agent. Users set and list secrets from inside pi, and the agent runs commands with those secrets without ever reading the values.

## Key Features

- Set secrets from pi with `/psst-set SECRET <VALUE>`
- List available secrets with `/psst`
- Built on the psst CLI and its encrypted local vault
- Installs via `pi install npm:@miclivs/pi-psst`
