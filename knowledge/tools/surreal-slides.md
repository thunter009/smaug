CLI that indexes presentation files with LlamaParse, stores structured slide data in SurrealDB and offers agentic natural-language search. Positioned as a higher-fidelity alternative to Claude Code's basic pptx skill.

## Key Features

- Two phases: preprocess/index, then agentic query
- Handles charts and tables without on-the-fly screenshots
- Built by LlamaIndex (@itsclelia)
