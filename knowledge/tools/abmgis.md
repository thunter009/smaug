Companion repository (~220 stars) for the book "Agent-Based Modelling and Geographical Information Systems: A Practical Primer". Each chapter has a subdirectory with models, data and other material. This is classic simulation modelling, not LLM agents.

## Key Features
- Chapters on ABM intro, designing and developing models, building with NetLogo
- GIS fundamentals and integrating ABM with GIS (raster and vector data)
- Modelling human behaviour, networks, spatial statistics
- Verification, calibration and validation of models
