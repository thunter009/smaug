Official DuckDB Claude Code plugin adding skills for local data exploration and session memory.

## Key Features

- read-file and query: query any DuckDB-readable file locally via CLI
- read-memories: store and query Claude memories in DuckDB
- attach-db: manage DuckDB state through a project .sql file
- duckdb-docs: full-text search over remote DuckDB docs
- Install: /plugin marketplace add duckdb/duckdb-skills
