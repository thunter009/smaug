Obsidian plugin that extends grouped views in Obsidian Bases (TypeScript, installed via BRAT).

## Key Features

- Collapse/expand groups, with collapse all / expand all and remembered state
- Drag and drop rows between groups (press-and-hold on mobile)
- Optional toolbar and per-group record counts
- Works in bases embedded in markdown and canvas files
