AI agent skill that scans iOS/macOS projects for App Store rejection patterns before submission. Builds on the asc CLI to pull metadata and checks it against 100+ Apple Review Guidelines.

## Key Features

- Checks competitor terms in metadata, missing privacy manifests, unused entitlements, banned AI terms in China storefront, misleading subscription pricing
- Guideline index plus 10 app-type checklists (games, AI apps, kids, health, macOS)
- Auto-fix suggestions where possible
- Install: npx skills add truongduy2611/app-store-preflight-skills
