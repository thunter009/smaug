Open-source AI job search agent that runs locally inside an AI coding CLI such as Claude Code or Codex.
It scores each job 1-5 against your CV, then tailors a resume and cover letter per application.
The user reviews each application and presses Submit.

## Key Features

- Scans job boards and scores each listing 1-5 against your CV before you apply
- Tailors an ATS-friendly resume and cover letter per job
- Generates interview prep material
- Keeps a job application tracker
- Runs locally in Claude Code, Codex, OpenCode, and similar CLIs
