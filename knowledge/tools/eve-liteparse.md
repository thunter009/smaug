Template from LlamaIndex that integrates LiteParse into Vercel's Eve agent framework. It provides read-only filesystem tools (resolve paths, list directories, read text files) paired with LiteParse for Markdown parsing, plus instructions for combining them, as a starting point to extend with channels, tools and skills.
