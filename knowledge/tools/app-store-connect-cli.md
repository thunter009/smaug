Fast, scriptable Go CLI for the App Store Connect API. Automates iOS, macOS, tvOS and visionOS release workflows (TestFlight, builds, submissions, signing, analytics, screenshots, subscriptions) from terminal, IDE or CI. v5.0.0 announced by @rudrank as a major release.

## Key Features

- Covers TestFlight, builds, submissions, signing, metadata sync, analytics, subscriptions
- `asc install-skills` installs a pinned pack of 25 agent skills for these workflows
- Homebrew-compatible, MIT license, Go
