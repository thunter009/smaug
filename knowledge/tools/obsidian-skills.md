Agent Skills package for Obsidian by kepano, about 50k GitHub stars. It follows the Agent Skills spec, so Claude Code, Codex, and OpenCode can all load it. It teaches agents to write Obsidian-flavored Markdown, Bases, and JSON Canvas files, and to drive the Obsidian CLI.

## Key Features

- obsidian-markdown: wikilinks, embeds, callouts, and properties in `.md` files
- obsidian-bases: create and edit `.base` files with views, filters, formulas, and summaries
- json-canvas: create and edit `.canvas` files with nodes, edges, and groups
- obsidian-cli: interact with vaults and develop plugins and themes
- defuddle: extract clean Markdown from web pages to save tokens
- knap: render Markdown templates from JSON or CSV data
