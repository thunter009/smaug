Browser-based forward and reverse geocoder using DuckDB-WASM over Overture Maps Parquet files (469M+ addresses, 39 countries), no backend.

## Key Features

- Country-aware address parsers (incl. Japan with kanji/chome handling)
- libpostal street-type synonym expansion in 27 languages
- Three-tier caching; H3 tile overlays on MapLibre GL
- Svelte 5 UI plus a framework-agnostic core TS library
