Lightweight S3-compatible object storage server in Go. Single binary, idles around 17 MB RAM, built-in web dashboard, encryption at rest. One-person project positioned as a MinIO alternative; README warns to evaluate before trusting data.

## Key Features

- S3-compatible API
- Single binary, very low memory
- Built-in web dashboard
- Encryption at rest
- Docker deployment
