Obsidian plugin (TypeScript, MIT, ~475 stars) that puts Claude Code, Gemini, Codex and Antigravity in one sidebar, each chat tab running a different provider. Aimed at researchers who write in Obsidian.

## Key Features

- Per-tab provider routing and same-tab consult between models.
- Inline diff editing, thinking blocks, MCP support.
- CLAUDE.md auto-mirror.
- 7 academic research skills as slash commands (manuscript editing, citation checks, peer-review workflows).
- Desktop only; needs the provider CLIs installed (`claude`, `gemini`, `codex`, `agy`).
