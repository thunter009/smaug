OpenAI repo that orchestrates coding agents from a project board. It polls the board for ticket changes and spawns an agent for each lifecycle stage of a ticket.

## Key Features

- Polls project boards for changes
- Spawns agents per ticket lifecycle stage
- Moving tickets replaces prompting an agent and opening a PR by hand
