Web and mobile UI wrapper around the Claude Code and Codex CLIs that runs on your existing subscription instead of API keys.

## Key Features
- Multiple projects in one UI
- Create git worktrees per session
- Spawn Docker containers for isolation
- Schedule Claude/Codex sessions
- Works from mobile and web
