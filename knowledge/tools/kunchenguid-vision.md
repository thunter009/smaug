Agent skill that mines a repo's history to draft a VISION.md, stress-tests it with 8-12 borderline hypothetical features, and iterates via an interactive review board. VISION.md states where the project is going; use it to triage feature ideas, detect drift in code review, and settle ambiguous product decisions.

## Key Features

- Reads project history to build context
- Proposes borderline feature ideas to force clarity
- Writes VISION.md for triage and drift detection
