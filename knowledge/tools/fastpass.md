fastpass (fastpass-cli) is a Claude-written CLI by Cory Wilkerson that adds Cloudflare Access to small vibe-coded apps with minimal friction. If the domain is already on Cloudflare, it wires up email, GitHub, or Google identity providers in seconds, saving UI clicks. Author's caveat: use at your own risk. GitHub API returned no README, so details come from the tweet only.

## Key Features

- Adds Cloudflare Access to a domain from the command line
- Wires email, GitHub, and Google IdPs
- Targets many small apps on Cloudflare-hosted domains
