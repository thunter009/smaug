Tool that probes local hardware and reports which LLMs will actually run on it. Per the tweet it handles MoE expert offloading, picks the best quantization for available RAM, and estimates tokens/sec before downloading weights. Described as essential for local dev.

## Key Features

- Hardware probing to match models to machine
- MoE expert offloading handling
- Quantization selection based on RAM
- Tokens/sec estimates before pulling weights
