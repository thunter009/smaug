# skill.color-expert

Agent skill that makes a coding agent a color science expert, with 113 reference files (~286K words) from Helmholtz to OKLCH. Works with Claude Code, Codex, Cursor and Copilot.

## Key Features

- SKILL.md with key facts, then INDEX maps, then deep references
- Covers color spaces, APCA/WCAG accessibility, palette generation, pigment mixing, history
- Evals folder for trigger and task prompts
- Install: git clone into ~/.claude/skills/color-expert
