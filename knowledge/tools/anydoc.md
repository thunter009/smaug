Firecrawl's open-source Rust engine converting Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV and PDF into clean GitHub-flavored Markdown in single-digit milliseconds. Powers Firecrawl /parse.

## Key Features

- Sub-5ms conversion; 500 docx files in 1.7s
- 13 formats with consistent Markdown output
- Bindings for Node.js, Python and WebAssembly; ships an Agent Skill
