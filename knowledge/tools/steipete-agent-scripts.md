Two open-sourced Codex loop skills from Peter Steinberger for maintaining repos with agents. Details below come from the tweet; the fetched SKILL.md content was empty.

## Key Features
- maintainer-orchestrator: wakes every 5 minutes, sorts issues/PRs into agent-handled / owner-decides / ignore; PRs must be green before escalating
- github-project-triage: scans open issues, PRs, CI and releases; buckets into autonomous / needs owner / close
- Combines with autoreview and computer-use skills so some work lands autonomously
