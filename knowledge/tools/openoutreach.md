Open-source, self-hosted CLI AI agent for B2B lead generation (eracle/OpenOutreach, Python, GPLv3). You describe your product and target market; it finds matching people from a licensed data provider, explains why each fits, and emails them from your own mailbox.

## Key Features
- `uv tool install openoutreach`, then bare `openoutreach` onboards, finds leads, sends
- Verbs: `run N`, `init`, `find N [emails]` (CSV on stdout), `send`, `status`
- No browser, no social account, no scraping; state in `~/.openoutreach`
- Ships a Claude Code plugin/skill (`find-leads`) that never buys addresses or sends unasked
- Hosted option at openoutreach.app
