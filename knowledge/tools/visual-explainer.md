Agent skill that renders diagrams, diff reviews, plan audits, data tables and project recaps as styled self-contained HTML pages instead of terminal ASCII art.

## Key Features

- Slash commands such as /diff-review and /plan-review produce HTML opened in the browser
- Reference templates plus CSS pattern library keep output consistently designed
- Installs for Claude Code, Pi, Codex, Cursor, OpenCode; optional MCP server, PPTX and video export
- No build step for normal use
