1,324-exercise fitness dataset with animation GIFs, 180x180 thumbnails, muscle-group and equipment data, and step-by-step instructions in multiple languages. It is the exercise data layer behind the LogPress workout app.

## Key Features

- 1,324 exercises with category, body part, equipment, target and muscle-group metadata
- Animation GIF and thumbnail per exercise (media from Gym visual, separate media terms)
- Instructions in up to 10 languages
- JSON data plus interactive HTML browser and setup guide
- MIT license plus media terms
