Local-first, file-based knowledge base that doubles as an agent memory layer. Uses fast lexical search (ferrosearch) instead of vector search, with progressive disclosure of context to agents.

## Key Features

- Obsidian-compatible vault with an agent-oriented CLI (init, overview, search)
- No vector search; native MiniSearch-compatible Rust engine
- First-class support for pi harness with self-distillation that learns during sessions
- Graph view built on Glimpse
