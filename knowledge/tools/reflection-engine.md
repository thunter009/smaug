Single downloadable prompt (from Kevin Rose's repo) that has an AI assistant mine its memory and chat history of you and write back a candid, evidence-grounded portrait: blind spots, contradictions, expensive habits, trajectory.

## Key Features

- 22 direct answers, each citing evidence
- Confidence score per answer plus one concrete thing to try this week
- Needs a top reasoning model with memory/chat history enabled
