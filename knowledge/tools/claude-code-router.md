Proxy in front of Claude Code that sends each request to the cheapest model able to handle it (e.g. Haiku for grep-style work, Opus only for hard parts). Cited as ~37k stars.

## Key Features
- Per-request model routing to cut Opus spend
- Sits transparently between Claude Code and providers
