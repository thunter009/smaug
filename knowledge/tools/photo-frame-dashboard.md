Guide and tooling by Wes Bos for taking over cheap locked-down Android photo frames (Skylight Calendar, BIUFRAME, Frameo clones). Unlock via ADB, root, back up the vendor firmware, replace the vendor app, and run your own web page full screen as a family dashboard.

Pitch: buy a roughly $50 frame, point a coding agent at the repo, and let it run. 1.5k stars; 70+ community builds (LCARS interface, retro weather channel, chess puzzles, Linux on a frame).

## Key Features

- ADB access, root and backup steps for locked-down frames
- Device index mapping each frame to its board and starting point
- Replace vendor app with full-screen custom web dashboard
- Agent-friendly instructions (Claude Code, Codex both work)
- Community builds gallery
