pstack is a set of agent skills. Its principles are concise skills (~10-20 lines) distilling good engineering practice. /poteto-mode holds an index and asks agents to name each principle that shaped a decision.

## Key Features

- Short principle files, invocable as /principle-<name>
- Agents must report 'Principles Named or Used' in replies
- Principles extracted from a year of correcting agents (e.g. Attack the Premise)
- Expected to compress further as models improve
