Pure-bash CLI by Jeffrey Emanuel that keeps hundreds of GitHub repos in sync: parallel clone/pull, conflict detection, JSON output and meaningful exit codes for CI. Basis of his /ru-multi-repo-workflow skill for agent-driven commit and sync across machines.

## Key Features

- Parallel clone and pull across many repos
- Conflict detection with JSON output for automation
- Meaningful exit codes for CI; installs via curl script or Homebrew
