# City2Graph

Python library that turns geospatial data (buildings, streets, transit feeds, OD matrices, POIs) into graphs for network analysis and Graph Neural Networks. Bridges GeoPandas, NetworkX and PyTorch Geometric.

## Key Features

- Graph construction from urban datasets
- GTFS transit graphs via DuckDB
- Proximity, contiguity and isochrone graphs
- Mobility flow analysis (bike-share, migration, pedestrian)
- PyTorch Geometric tensor conversion
