LlamaIndex's LiteParse parses files into clean structured Markdown and ships as a library or one-click skill for any agent. Jerry Liu argues agent loops default to light parsers like pypdf/pdftotext before vision, causing hallucinated context and bad retrieval, and that LiteParse should be the parser of choice for cost, accuracy and speed.
