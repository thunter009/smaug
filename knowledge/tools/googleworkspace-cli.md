Official Google CLI for Workspace (Drive, Gmail, Calendar, Sheets, Docs). Written in Rust, distributed via npm, and ships agent skills installable through the skills.sh ecosystem. GitHub API returned no README at capture time, so details come from the tweet.

## Key Features

- Covers Drive, Gmail, Calendar, Sheets, Docs and more from one CLI
- Install: `npm i -g @googleworkspace/cli`
- Agent skills: `npx skills add github:googleworkspace/cli`
