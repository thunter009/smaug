OpenAI's open-source Codex Security CLI and TypeScript SDK. It finds, validates and fixes security vulnerabilities in code, and plugs into CI/CD as a scan step. Announced as an early release by @thsottiaux and @OpenAI, who ask for feedback.

## Key Features
- Scan repositories for security vulnerabilities
- Track findings across runs
- Verify that fixes work
- Add security checks to CI/CD
- CLI plus TypeScript SDK
