Free, open-source macOS app to browse, edit and manage AI coding agent skills in one place. Covers Claude Code, Cursor, Codex, Windsurf and Amp. Requires macOS Sequoia; source available under FSL-1.1-MIT.

## Key Features

- Single UI for skills across five coding agents.
- Browse and edit skill files.
- Native macOS app (v1.16.0 at time of bookmark).
- Author (Shpigford) says the stock-macOS look feels bland and is seeking design personality.
