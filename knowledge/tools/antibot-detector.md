Free Chrome extension from Scrapfly that shows how a website defends against bots. It identifies anti-bot systems (Cloudflare, Akamai, DataDome, Shape Security), CAPTCHAs (reCAPTCHA, hCaptcha) and fingerprinting scripts in real time, with confidence scores per match.

## Key Features

- Real-time detection while browsing, per-protection category and confidence score
- Advanced capture tools for inspecting detections
- Useful for scraper authors choosing a bypass strategy
