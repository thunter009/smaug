Real-time, local speech-to-text server (Python, ~11k stars) with streaming ASR, speaker diarization (Sortformer/Diart) and optional translation. Exposes OpenAI-compatible REST, Deepgram-compatible WebSocket and a native streaming API, so migrating from hosted services needs little code change.

## Key Features

- Pluggable backends: Whisper, Faster-Whisper, MLX Whisper, SenseVoice, Voxtral, Qwen3-ASR, NVIDIA Canary
- Runs on Apple silicon, CPU-only or NVIDIA GPU; Apache 2.0
- Multi-user backend; audio stays on your machine
