Open-source agent skill set (MIT, Claude Code compatible) that validates a startup idea before code is written. Produces what a strategy consultant would: market research, competitive battle cards, positioning, financial projections, and a 30-day action plan, and says so if the idea should die.

## Key Features

- startup-design: 8-phase full strategy, customer discovery gate, 30+ deliverables
- startup-competitors: battle cards, pricing landscape, feature matrix from reviews and forums
- startup-positioning and further skills for pricing and planning
- ~1.2k stars, v1.10.0
