Open-source (MIT) plugin that turns a codebase or docs into an interactive knowledge graph you can explore, search, and question. Works with Claude Code, Codex, Cursor, Copilot, Gemini CLI.

## Key Features
- Five parallel agents: scan, extract relationships, identify layers, build tours, validate graph
- Dashboard with clickable nodes, plain-English explanations, semantic search
- Q&A grounded in the codebase
- Diff impact analysis before commit
