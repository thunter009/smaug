Self-evolving memory OS for LLM agents: persistent memory, hybrid retrieval and cross-task skill reuse. The OpenClaw plugin runs locally on SQLite.

## Key Features

- Moves memory out of the prompt into a system layer; claimed ~70% token savings (Tw93)
- Conversations become tasks, then reusable skills
- Multiple agents can share knowledge
