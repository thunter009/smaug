Pake turns any webpage into a native desktop app for macOS, Windows, and Linux with a single command. Version 3.10.0 adds multi-window support, internal-link regex control, and packaging fixes. Pitch: ship the web version first, validate with users, then package desktop.

## Key Features

- One-command packaging of any URL into a native app
- `--multi-window` flag with Cmd+N on macOS and tray integration
- `--internal-url-regex` for fine-grained internal link handling (multi-route AI dashboards)
- Better Windows icons (prioritized 256px ICO entries)
- Retina DMG background fix for macOS builds
