ByteDance/Volcengine open-source context database for AI agents. Unifies memory, resources and skills under a filesystem paradigm with viking:// URIs.

## Key Features

- Filesystem-style management of memories, resources and skills
- Three-tier L0/L1/L2 context loading to cut token use
- Directory-scoped hierarchical retrieval instead of flat vector pool
- Self-evolving memory
