Local-first, hardware-bound key management and encrypted secret storage on the Mac Secure Enclave, so agents can use secrets without reading them.

## Key Features

- keypo-signer: Secure Enclave P-256 keys, encrypted vault, iCloud backup
- No cloud provider dependency; keys not extractable by agent or Apple
- Pitched as a programmable password manager for Claude Code
