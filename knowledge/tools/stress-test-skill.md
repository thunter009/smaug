Agent skill that stress-tests technical plans before you build: verifies claims against real docs, runs proof-of-concept experiments, and updates the plan. Motivated by the observation that models are lazy and unaware of their own capabilities, so upfront POCs raise the odds that the agent's v1 is useful. 21 stars at bookmark time; README was empty in the fetched data.

## Key Features

- Verifies plan claims against real documentation
- Runs small POCs for assumptions the model is not fully confident in
- Updates the plan with findings before implementation
