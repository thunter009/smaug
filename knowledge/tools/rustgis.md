RustGIS is a free, open-source GIS written in pure Rust for mapping, analyzing and sharing geospatial data. It runs natively on Windows, macOS and Linux, and in the browser via WebAssembly. Data stays local unless sent to a user-chosen AI model; every action is a scriptable command.

## Key Features

- Formats: GeoJSON, CSV, Shapefile, GeoParquet, Flatgeobuf, PMTiles, GeoTIFF/COG, web and vector tiles, MapLibre styles; 3D globe
- 1,000+ geoprocessing tools (GeoLibre, Whitebox) for terrain, hydrology, LiDAR, ModelBuilder workflows
- Cartography: symbology, labels, page layouts, map series, PDF export
- Editing with snapping, templates, attribute rules, undo
- AI Assistant that operates the map via natural language (Anthropic, OpenAI, etc.), 15 UI languages
