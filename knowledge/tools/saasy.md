Open-source collection of reusable multi-tenant SaaS starter templates. Each variant is a standalone pnpm + turbo workspace; variants share no code.

## Key Features

- B2B variant: Next.js 16 with BetterAuth (`b2b-betterauth-next/`).
- B2C variant: Vite + React with Clerk (`b2c-clerk-vite/`).
- Email/password and OAuth sign-in, workspace creation and switching.
- Role-based membership, invitations, Stripe billing with plan entitlements, slug-based multi-tenant routing.
- Start by copying one variant folder, then `pnpm install && pnpm dev`.
