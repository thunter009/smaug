# Marble Skill Taxonomy

Open, structured taxonomy of what children learn across primary/elementary years, split into fine-grained micro-topics and wired into a prerequisite graph aligned to national curriculum standards. Produced by Marble (withmarble.com). About 7.3k GitHub stars.

## Key Features

- 1,845 micro-topics: one teachable idea each, with plain-language description, mastery evidence criteria, type (conceptual, procedural, representational, language, meta), subject, domain and approximate age range.
- 3,941 prerequisite edges forming a DAG, tagged hard or soft, 9 subjects.
- Alignment to curriculum standards (e.g. NGSS, UK national curriculum).
- Parent-friendly domain cluster summaries.
- Teaching research per topic (misconceptions, common methods), about 24 MB JSON; the tweet announces new coverage of 1000+ science and maths topics.
- JSON files in `data/` with JSON Schemas in `schema/` and a manifest with SHA-256 checksums.
