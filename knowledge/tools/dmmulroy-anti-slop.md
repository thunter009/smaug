Opinionated Oxlint rules by Dillon Mulroy that reject low-evidence, low-signal TypeScript/JavaScript patterns. Meant to be vendored: copy the rules into your repo and adapt them. A bundled agent skill handles initial copy and configuration.

## Key Features

- Oxlint ruleset for TS/JS
- Vendored, not an npm dependency
- Bundled agent skill for setup
