Glass is a fork of the Zed editor aimed at being an agentic development environment (ADE). The GitHub API returned no description or README, so details come from the author's tweet.

## Key Features

- Fork of Zed with a built-in browser (Chromium via CEF)
- Full IDE terminal
- ACP (Agent Client Protocol) for AI coding
- BYOK across many providers
- Reuse existing Claude Code, Codex, Gemini, Cursor subscriptions
- Next release promises UI improvements, fixes, new layouts
