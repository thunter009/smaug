# Compass MCP

Open source MCP server sharing task state across Claude Chat, Cowork and Code via plain markdown files.

## Key Features

- 6 tools (add_task, get_tasks, complete_task, ...)
- 2 markdown files in ~/compass-data, no database
- Same tasks and project contexts visible in Chat, Cowork and Code
