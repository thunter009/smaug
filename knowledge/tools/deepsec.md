Agent-powered vulnerability scanner from Vercel Labs. Runs on your own infrastructure for on-demand review of all code in large existing repos. TypeScript, Apache-2.0, about 8.2k stars.

## Key Features
- Uses best models at maximum thinking level (tunable via `--thinking-level`).
- Scans can cost thousands to tens of thousands of dollars on large codebases.
- Work fans out across worker machines in parallel.
- Interrupted runs resume: re-run the same command and it skips analyzed files.
