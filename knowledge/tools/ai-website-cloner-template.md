A TypeScript template that uses AI coding agents (Claude Code, OpenCode and others) to clone a website from a URL into a Next.js project. About 37k stars at capture. MIT license.

## Key Features

- One-command website cloning via AI coding agents
- Next.js and shadcn/ui based template
- Works across multiple agent platforms
- Topics: reverse-engineering, web-scraping, automation, boilerplate
