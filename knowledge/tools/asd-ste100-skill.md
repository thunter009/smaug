Claude Code skill that rewrites dense, ambiguous English into ASD-STE100 Simplified Technical English, the controlled language built for aircraft maintenance manuals. It targets AI agents reading other agents' output, tool descriptions, error messages and inter-agent instructions, where no one can ask what was meant. Repo had about 5,558 stars at capture.

## Key Features
- Strict mode for procedures, error messages and tool descriptions; STE-flavored mode for READMEs, PR descriptions and prose
- Flags violations per sentence: passive voice, complex tenses, multi-instruction sentences, noun clusters, phrasal verbs, nominalizations, hedges, marketing adjectives
- Rewrites flagged sentences, with before/after examples
- Related community pieces: STE skill kit, writing-styles, runbook skill, STE checker
