Planned open-source database and algorithm for "Real API Pricing": subscription price divided by actual token allowance, yielding an effective $/MTok per plan and a Pareto frontier chart. Repo content was empty at fetch time (README not available); details come from the tweets.

## Key Features

- Ranks plans by effective cost per million tokens (e.g. GPT-5.6 Luna on ChatGPT Pro 20x at $0.00083/MTok, #1).
- Shows cheap-reputation models (DeepSeek V4 Flash #31, Grok 4.6 #63) ranking worse than expected.
- Data from public info and user screenshots.
