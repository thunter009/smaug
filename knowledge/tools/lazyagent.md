lazyagent is a lazygit-style terminal UI (Go, MIT, ~193 stars) that monitors Claude Code, Cursor, OpenCode, pi and more from one screen. It reads the session files each agent already writes to disk, so it does not wrap, proxy or modify the agents.

## Key Features
- Single dashboard across multiple coding agents
- Shows current activity, last 5 messages, token usage and estimated cost, git branch, last file touched, braille activity sparkline
- macOS menu bar app and HTTP API with Server-Sent Events, in one dependency-free binary
- Install: `brew tap illegalstudio/tap && brew install lazyagent`
