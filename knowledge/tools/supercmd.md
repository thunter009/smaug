Open-source Raycast alternative that runs existing Raycast extensions unmodified, with built-in voice dictation, read-aloud and AI.

## Key Features
- Raycast extension compatibility, zero migration
- Voice dictation via ElevenLabs Whisper; SuperCmd Read text-to-speech
- AI support including local Ollama (no API key)
- Memory recall via Supermemory, works offline
- Planned: AI skills integration (OpenClaw-style)
