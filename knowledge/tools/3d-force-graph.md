3D force-directed graph component by vasturiano, built on ThreeJS/WebGL, for rendering node-link graphs interactively.
Jeffrey Emanuel says bv's built-in graph visualization is based on it, but he sees graph visuals as mostly entertainment.

## Key Features

- Force-directed layout of nodes and links in 3D
- WebGL rendering via ThreeJS
- Interactive navigation of graph data
