Zig CLI (~2.8k stars) to switch and manage multiple Codex accounts. Works with Codex CLI, the VS Code extension and the Codex App. Installs via npm.

## Key Features

- Switch between several Codex subscriptions/accounts from one command
- Supports Codex CLI, VS Code extension, Codex App (restart client after switching)
- Install with `npm install -g @loongphy/codex-auth` or run via `npx @loongphy/codex-auth list`
- Companion fork `codext` offers automatic switching without restart
