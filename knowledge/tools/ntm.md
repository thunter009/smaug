Open-source tool by Jeffrey Emanuel for running swarms of coding agents across any harness (Claude Code, Codex, gemini-cli) instead of a single vendor's multi-session UI. GitHub API returned no README; description is from the tweet.

## Key Features
- Works with all agent harnesses and models, avoids lock-in to one vendor's desktop app
- Mixes models for diversity of thought across harnesses
- Pairs with Agent Mail, beads, and the /ntm and /vibing-with-ntm skills
- Companion guide: Agentic Coding Flywheel complete guide
