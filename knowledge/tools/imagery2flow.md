Code for predicting origin-destination human mobility flows between city sub-regions from high-resolution satellite imagery, avoiding costly and slow traveler surveys.

## Key Features

- Deep learning on satellite imagery to estimate OD flows
- Use cases per author: travel demand estimates, disease-spread modeling in data-poor regions, development impact assessment
