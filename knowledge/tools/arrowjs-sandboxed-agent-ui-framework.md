ArrowJS is a tiny, zero-dependency, type-safe JS framework with no build step. Its sandbox isolates agent-generated UI inside WebAssembly while rendering real inline DOM in the host app (no iframes, no predefined components).

## Key Features

- Zero dependencies, no build step
- WASM sandbox for untrusted agent-generated UI
- Inline DOM rendering, no iframes
- Demo from the tweet: infinite canvas where a sketched box becomes a rendered app
