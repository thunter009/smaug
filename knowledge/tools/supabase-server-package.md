Public beta package that handles JWT verification, client setup, CORS, and request context for server-side code across Edge Functions, Vercel, Workers, Hono, and Bun.

## Key Features

- withSupabase wrapper declares auth mode and provides a SupabaseContext
- Context includes user-scoped client, admin client, verified identity, JWT claims
- Works across Edge Functions, Vercel Functions, Cloudflare Workers, Hono, Bun
- Replaces copy-pasted _shared setup code seen in 25,000 analyzed functions
