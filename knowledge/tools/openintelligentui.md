Open-source chat interface from CopilotKit that turns questions into interactive answers: explanations, comparisons and throwaway working tools. The agent picks per request between plain text, a native component, or a generated custom interactive UI. Built on CopilotKit and AG-UI. MIT, TypeScript, about 3.9k stars.

## Key Features

- Understand: step through mechanisms, tweak variables (3D demos, Monty Hall simulation)
- Compare: tables and charts of criteria and tradeoffs
- Make a tool: calculators, planners rendered in chat, disposable
- Renders with your own components and design system
- Works with any LLM and agent framework; no lock-in
