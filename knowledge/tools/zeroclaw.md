ZeroClaw is a Rust rewrite of the OpenClaw AI agent, optimized for speed and a tiny footprint.

## Key Features

- 3.4MB binary vs 28MB for OpenClaw
- Cold start 0.38s vs 3.31s
- Status command ~0s vs 5.98s
- RAM for status 7.8MB vs 1.52GB (figures from @dabit3's quick benchmark)
