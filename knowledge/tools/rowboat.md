Open-source personal AI assistant that indexes email, meetings, Slack, and assistant conversations into a backlinked Markdown knowledge graph. Adds docs, whiteboard, and email surfaces. Works solo or with a team.

## Key Features

- Living Obsidian-style knowledge graph built from email, meetings, and chats
- Typed entities (decisions, commitments, deadlines, people) as separate Markdown files with backlinks
- Background agents on a schedule, e.g. daily briefings
- Work surfaces: email client, notes, browser, code mode, meeting note taker, per-project workspaces
- Plain Markdown storage; open in Obsidian, edit, or delete
- Bring your own model: Ollama, LM Studio, or hosted APIs
