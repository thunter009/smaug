Google Labs' DESIGN.md specification for describing a design system to coding agents. Trevin Chow urges repos adding a DESIGN.md to follow the spec's frontmatter format rather than prose-only descriptions. (Repo content was not fetched; description is from the tweet.)

## Key Features
- Standard DESIGN.md format with structured frontmatter
- Prose design-system description plus machine-readable tokens
- Aimed at consistent agent-readable design context across repos
