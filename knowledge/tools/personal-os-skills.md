Claude Code plugin marketplace by ArtemXTech with skills for Obsidian-based personal workflows (543 stars, Python).

## Key Features

- Install via `/plugin marketplace add ArtemXTech/personal-os-skills`
- granola: sync Granola meeting notes to Obsidian from the local cache, no API
- wispr-flow: analyze Wispr Flow voice dictation data (stats, search, export, dashboard)
- tasknotes: manage Obsidian tasks via the TaskNotes API
- notebooklm / notebooklm-import: turn expert podcasts into protocols; import notebooks into Obsidian
