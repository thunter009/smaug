# DingDuff

Free MCP connector for Claude, built by two practicing lawyers in Austin, Texas. It connects Claude to millions of court opinions, statutes, regulations and court rules, plus federal court filings (PACER). Per the tweet, the founders' own testing found it matched or beat Westlaw AI. That claim is unverified.

## Key Features

- Free for any lawyer to use
- Claude connector via MCP
- Coverage: opinions, statutes, rules, PACER filings
