Agent skill encoding a Swiss International Style design system (grotesque type, grayscale palette, grid, whitespace). PR #1 extends it to cover behavior, not just looks.

## Key Features
- Install: `npx skills add zeke/swiss-design-skill`
- PR references Vercel's web-interface-guidelines skill for a11y, focus, forms, perf, hydration
- Inlines the core typographic rules
- Demo site: https://swiss.ziki.boo/
