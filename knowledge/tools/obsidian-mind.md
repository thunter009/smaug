A self-organizing Obsidian vault that gives AI coding agents persistent memory. Built for Claude Code, with working hooks for Codex CLI and Gemini CLI. The repo is TypeScript with about 5.4k GitHub stars.

## Key Features

- Persistent agent memory: sessions start with North Star, active projects, and recent notes loaded
- Slash commands such as /om-standup, /om-dump, and /om-incident-capture
- Same hooks, commands, and vault across Claude Code, Codex CLI, and Gemini CLI
- Obsidian CLI integration and optional QMD semantic search
- Installs via ShardMind (`shardmind install github:breferrari/obsidian-mind`) or git clone
