## Key Takeaways

- Diffs the branch against a known-healthy baseline (usually `main`) and feeds it to the model.
- Prompt asks the model to find every reason the code should not ship; modeled on aviation pre-flight checks and grill-me.
- Author reports a month of use, with many bugs caught before prod.
