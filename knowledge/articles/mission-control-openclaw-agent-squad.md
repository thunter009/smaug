Guide to running 10 OpenClaw (formerly Clawdbot) agents as a team with a shared Mission Control dashboard built on React and Convex. Covers the gateway, sessions, task delegation and threaded agent collaboration.

## Key Takeaways

- Multiple OpenClaw sessions, each with its own personality and context, form a squad
- Gateway daemon runs 24/7, manages sessions, cron jobs and channel routing
- Shared workspace keeps context, task assignment and progress tracking
- Author productised it as MissionControlHQ.ai
