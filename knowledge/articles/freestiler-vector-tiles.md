# freestiler: Fast Vector Tile Generation from R/Python

freestiler is an R/Python package by Kyle Walker that generates vector tiles from spatial data, including DuckDB queries. Demo: 2.8M Colorado jobs from a 146M-row DuckDB database, tiled and shown on a MapLibre map in seconds.

## Key Takeaways

- Generates vector tiles directly from DuckDB queries
- Scales to millions of features in seconds
- Output serves straight into MapLibre maps
