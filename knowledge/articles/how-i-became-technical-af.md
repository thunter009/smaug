A non-technical PM ranked top 1% of engineers at small startups on Weave by pairing coding agents with metaphors, copied open-source ideas, and Socratic management.

## Key Takeaways

- Have the agent explain software concepts via a consistent metaphor (restaurant kitchen)
- Internet brain workflow: copy existing open-source implementations, keep a knowledge base with research and proposals folders
- Run a research loop: discovery, research, spec, build
- Manage the agent like a manager using the Socratic method
