X article on turning Obsidian into a versioned prompt library that Claude Code reads and executes. Argues chat windows lose good prompts; markdown files make them reusable assets.

## Key Takeaways

- Prompts in chat are ephemeral; store each as its own `.md` file with a descriptive name (e.g. `thread-writer-v2.md`).
- Vault layout: `/Prompts` with subfolders by use case (Research, Writing, Crypto-Analysis, Content-Creation, Code, Templates, Experiments).
- `/Experiments` holds unproven prompts; promote only after at least five consistent uses.
- Every prompt note follows one consistent template so the library stays searchable.
- Claude Code reads the vault locally, turning prompts into files the CLI can act on.
