Loop 002 in Forward Future's Loop Library: a bounded refactoring workflow for coding agents that live-tests the system, runs an independent review, commits checkpoints, and records progress.

## Key Takeaways

- Prompt: refactor until happy with architecture; after each significant step live-test, run autoreview, commit.
- Track progress in /tmp/refactor-{projectname}.md so the loop survives context loss.
- Loop Library is a curated, submittable list of repeatable agent loops with clear stopping conditions.
