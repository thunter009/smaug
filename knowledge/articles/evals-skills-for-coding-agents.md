Hamel's blog writeup on teaching a coding agent to run product evals, accompanying the evals-skills plugin. Adds an error-discovery skill (review app with intelligent sampling, failure-mode grouping) and an evals-start routing skill.

## Key Takeaways

- Give the agent a file of outputs/traces; it builds a custom annotation UI
- Agent groups human notes into failure modes and finds related examples
- Start skill routes to trace analysis or auditing an existing eval pipeline
