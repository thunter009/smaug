Thariq (Anthropic) catalogs lessons from hundreds of internal Claude Code skills. Skills are folders with scripts, assets and data, not just markdown.

## Key Takeaways

- Skills cluster into types: library/API reference, product verification, data analysis, business automation, scaffolding, code quality/review, CI/CD, runbooks, infra ops
- Verification skills deserve heavy investment (scripts, assertions, recordings)
- Include gotchas and reference code in skill folders
- Skills can register dynamic hooks and store logs to stay consistent across runs
