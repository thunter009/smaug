An engineer with no design background assembles a three-layer agent harness to ship design end to end. Layer 1 is installable design skills that borrow expertise from seasoned designers.

## Key Takeaways

- Impeccable (pbakaus): 20+ commands (/audit, /polish, /animate, /typeset) catching AI-looking UI anti-patterns; /delight is the favorite
- Emil Kowalski design-engineer skill encodes animation and polish details
- Interface Design plugin persists design decisions in system.md across sessions
- UI Skills (ibelick): 15 open-source skills for baseline UI, accessibility, motion
