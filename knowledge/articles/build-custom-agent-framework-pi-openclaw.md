Guide to PI (badlogic/pi-mono), the layered monorepo that powers OpenClaw, walking from LLM calls up to a full agent terminal UI with session persistence and custom tools.

## Key Takeaways

- pi-ai: multi-provider LLM communication.
- pi-agent-core: agent loop with tool calling.
- pi-coding-agent: full coding agent with built-in tools, sessions, extensibility.
- pi-tui: terminal UI building blocks.
- Composing layers avoids lock-in to one abstraction.
