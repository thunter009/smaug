Survey of nine ways to get Claude Code to scrape data, from plain prompting to paid scraper services. A YouTube video with live demos accompanies it.

## Key Takeaways

- Way 1: just ask Claude Code to scrape the site into CSV or SQLite; it writes and runs a Python script.
- Way 2: ask it to find the underlying API endpoints; that nudge often beats a plain scrape request.
- Way 3: ScrapeCreators gives API endpoints for social media; wrap it in a skill once.
- Way 4: Apify actors are rentable scrapers (e.g. Google Maps); paid after trial.
- Way 5: Firecrawl to markdown, then structured extraction, for unstructured pages.
- Ways 6-9 are covered in the full article.
