Thariq (Anthropic) announces Claude Code Tasks replacing TodoWrite: a primitive with dependencies and blockers, stored on the filesystem so multiple sessions and subagents can collaborate.

## Key Takeaways

- Opus 4.5 tracks state well enough that TodoWrite became unnecessary for small work
- Tasks store dependencies in metadata and broadcast updates across sessions
- Inspired by community projects like Beads (Steve Yegge)
- Share a list via `CLAUDE_CODE_TASK_LIST_ID`
