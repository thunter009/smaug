Eleanor Konik describes using Claude with the filesystem MCP server to clean up a 12-million-word Obsidian vault. Article body was not extracted; summary is from the tweet and page description ("MCP servers are unusually reliable and useful compared to most AI tools").

## Key Takeaways
- Fixed inconsistent frontmatter, disliked numbered folder names, daily-note reformatting and broken links from bulk operations
- Workflow: ask Claude to study the patterns in a folder, then write a script mapping information A to location B
- Spot checks and a few iterations were enough; most of it done in minutes
- Non-developer perspective on what AI is good for
