# The Tufte Test: Teaching an AI Agent to Make Better Data Visualizations

Goodeye Labs writeup on getting an AI agent to pass a Tufte test by decomposing 'make it better' into discrete pass/fail dataviz criteria: remove 3D effects, direct labels, annotations, fixed palette.

## Key Takeaways

- Vague feedback gives agents nothing; concrete criteria drive improvement
- One principle per iteration shows a clear before/after progression
- Expertise can be deployed as an API of checkable criteria
