Nodes is a markdown writing app for macOS. Notes stay local on the Mac, link to each other with double brackets, are organized with tags, and are searched on-device. It shows a graph of linked documents. The authors open-sourced their rendering engine so others can build alternatives. Tiers: free demo (16 nodes, 4 tags), Alexandria $12.99 one-time (no caps, import/export), Rosetta $17.99 (adds an agent).

## Key Takeaways

- Local-first, wiki-link style markdown notes with a document network graph
- Requires macOS 14+; sold through the App Store
- State-of-the-art rendering engine is open source (github.com/nodes-app)
