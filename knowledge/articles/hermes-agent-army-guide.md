## Key Takeaways

- Hermes (MIT, Nous Research) runs on a VPS, Mac mini, laptop, Docker or Android and connects to Telegram, Discord, Slack, WhatsApp and iMessage.
- Author keeps Claude Code as desk-side daily driver; Hermes is the on-the-go, cron-driven agent.
- Five pillars: Memory (user.md, memory.md, SQLite session search), Skills (procedural playbooks with YAML front matter and progressive disclosure), Soul (soul.md personality), Crons, Self-Improving Loop.
- Example crons: daily AI news briefing, YouTube comment replies, morning business summary, server health checks, research reports.
- Keep business context, skills and memory in a shared GitHub repo so Claude Code, Hermes, OpenClaw and Codex can all plug in.
