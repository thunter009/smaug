Ole Lehmann turns Karpathy's autoresearch loop into a skill that auto-improves any other Claude skill. It runs the skill, scores output against a yes/no checklist, makes one small prompt change, keeps or reverts. His landing page copy skill went from 56% to 92% pass rate.

## Key Takeaways

- Loop: run, score, find failures, one small change, rerun, keep if score up else revert
- You only supply the scoring checklist defining "good"
- Works in Claude Code and Cowork on anything measurable
- Reported result: 56% to 92% quality-check pass rate with no manual work
