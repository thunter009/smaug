Skill spec that has an OpenClaw agent produce a daily digest of AI self-improvement material (harness patterns, memory, multi-agent coordination) and review it against its own setup.

## Key Takeaways

- Cron job at set time scans tiered sources (Anthropic Engineering, Simon Willison, Latent Space, X, HN, arXiv)
- Dedupes against memory/ai-digest-posted.json before posting
- Uses Brave Search API plus an x-research skill; filters to items relevant to agent improvement
