Jeffrey Emanuel consolidates his Agent Flywheel methodology into one canonical guide on planning, bead (task) creation, and running agent swarms. He built it by pulling his X threads with xf and mining real usage with cass, plus a shorter Core Loop guide for beginners.

## Key Takeaways

- Core of the Flywheel is 3 tools: Agent Mail (coordination), beads_rust (tasks), beads_viewer (graph triage for next best bead)
- Layer on dcg (destructive command guard), cass (session search), ubs (bug scanner) after the core loop
- Useful polish prompt: reread the doc as a newcomer and add, never remove, to improve clarity
- Guide is updated as the methodology evolves
