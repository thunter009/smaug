Curated list of favorite MCP servers for full-stack web development, grouped by workflow stage, with discovery sources (official repo, mcpservers.org, Glama).

## Key Takeaways

- MCP decouples the LLM from tools, replacing brittle custom API glue with one reusable server per service.
- Learn/Create: Context7, web search, GPT Researcher, Figma, Magic UI.
- Build/Data: filesystem, Desktop Commander, E2B sandbox, Git/GitHub/GitLab, Semgrep, DB MCPs, Stripe.
- Test/Run: Playwright, Chrome DevTools, BrowserStack, Netlify, Vercel, Sentry, Datadog.
- Work/Automate: Slack, Notion, Obsidian, Task Master, n8n, Zapier.
