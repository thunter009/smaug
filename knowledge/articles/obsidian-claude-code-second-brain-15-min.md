Guide to a 15-minute AI second brain: an Obsidian vault of plain markdown with Claude Code running inside it, steered by a CLAUDE.md so each session builds on prior context.

## Key Takeaways

- Only two tools: Obsidian (free, local markdown, no lock-in) and Claude Code (needs a ~EUR 20/mo Claude subscription).
- Problem framed: notes pile up unused and chat AIs forget you each session; vault access gives persistent personal context.
- Setup steps: create vault structure, connect Claude to the vault, write a CLAUDE.md describing the vault and your voice.
- Compounding effect: the AI improves each session as the vault and CLAUDE.md grow.
- Starter use cases: organize inbox, find connections between notes, draft content from your own thinking.
- A YouTube walkthrough accompanies the post (youtu.be/2mAGV7MQd04).
