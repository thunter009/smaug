# Using Git with Coding Agents

Draft chapter of Simon Willison's Agentic Engineering Patterns guide. Explains why version control is the safety net for coding agents and how to use Git's history, branches and commits with them.

## Key Takeaways

- Git records how code changes so agent mistakes can be investigated and reversed
- Cloned repos carry full history, so agents can dig through it with no network cost
- Staying aware of Git's capabilities beats memorizing commands; agents can run them for you
