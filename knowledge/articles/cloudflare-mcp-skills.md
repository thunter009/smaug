Cloudflare changelog: the Cloudflare API MCP server now serves Cloudflare skills. Clients connect and discover them with `skills/list`.

## Key Takeaways
- Skills are delivered over MCP, not installed separately.
- Discovery uses the `skills/list` method.
- Page also registers WebMCP tools (docs search, list products) in-browser.
