Ona (ex-Gitpod) CEO argues background coding agents cannot run on laptops; standardized cloud dev environments are the real prerequisite.

## Key Takeaways

- Stripe Minions merge 1000+ agent PRs/week; Ramp's agent authors 57% of merged PRs; Ona's agents authored 88.5% of its merged PRs.
- Shared trait is early standardized dev environments, not a special harness or model.
- Cloud dev environments were right but never urgent until fleets of agents needed isolated, fully provisioned sandboxes.
