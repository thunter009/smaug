Comparison of five agent search APIs (Brave LLM Context, Tavily, Exa, Perplexity Sonar, Firecrawl) after Microsoft killed the Bing Search API in Aug 2025. Argues search context quality matters more than model choice. Source text was truncated in capture.

## Key Takeaways

- Brave LLM Context API (Feb 12, 2026): own 35B+ page index, extracts ranked "smart chunks", under 600ms p90, token budgets, Goggles filtering, SOC 2 Type II, zero data retention
- Brave eval, 1,500 queries: Ask Brave (Qwen3 + LLM Context) scored 4.66/5, beating ChatGPT 4.32, Google AI Mode 4.39, Perplexity 4.01; only Grok 4.71 higher
- Tavily is the default in LangChain/LlamaIndex, 800k+ developers, with Search, Extract and more endpoints
- Exa claims sub-200ms; Perplexity Sonar does multi-step research
