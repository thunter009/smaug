Argues single-file skills cannot hold deep domain knowledge; instead build networks of small markdown skill files linked by wikilinks, each with a YAML description so agents can scan before reading.

## Key Takeaways

- Skill graph: many composable files, one complete thought each, connected via wikilinks.
- YAML descriptions let the agent scan nodes without reading whole files; MOCs organize sub-topics.
- Fits domains like trading, legal, or company knowledge that cannot fit in one file.
- The arscontexta Claude Code plugin scaffolds a graph (~250 files) and fills it via /learn and /reduce.
