Walkthrough of a six-year Obsidian vault paired with Claude. Keeps AI-generated material (meeting transcripts, repos, company skills) in a separate Claude folder so the hand-written vault and its knowledge graph stay clean, while Claude can read both.

## Key Takeaways

- One dedicated Claude folder with three subfolders: Github (repos, PRDs, research, company skills "Zkills"), Meeting notes (Granola export via Raycast), Obsidian vault
- Separate personal writing from AI-generated notes to avoid diluting the graph
- Vault has 5 folders: Polaris (goals), Logs (daily notes), Commonplace (atomic notes), Outputs (shareable writing), Utilities
- Navigation by folders, nested tags (portable, filterable by Claude) and manual backlinks; Claude suggests missed connections via a custom command
- "Polaris" and "Top Of Mind" notes act as guiding context so Claude challenges assumptions and notices what the author avoids writing about
