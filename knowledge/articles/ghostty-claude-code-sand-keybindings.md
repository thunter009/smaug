Daniel San moved from VSCode's fragile terminal to Ghostty for long Claude Code sessions. He organizes split-panel shortcuts with the SAND mnemonic and pairs it with lazygit, yazi and git worktrees.

## Key Takeaways
- S Split: Cmd+D right, Cmd+Shift+D down
- A Across tabs: Cmd+T, Cmd+Shift+Left/Right
- N Navigate: Cmd+Alt+Arrows, Cmd+Shift+E equalize, Cmd+Shift+F zoom
- D Destroy: Cmd+W
- Layout: Claude Code left, lazygit and yazi right; 1-3 Claude instances on worktrees
- Config available via a shared gist
