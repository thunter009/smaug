Daloopa founder Thomas Li argues AI is a "ladder" over the software moat: customers skip the tool layer and go straight to outcomes. Software = UI (advantage, not moat) + data/content. Once users can describe problems to an agent, the business-logic layer moves to the customer, and durable value shifts to proprietary data an LLM cannot get itself.

## Key Takeaways

- Moat vs advantage: advantages can be eroded by "being better"; a moat needs a disruptive force. Startups are in the ladder business.
- Software economics relied on habit and lock-in, which gave predictable cash flows, which fed private-debt-funded buyouts.
- AI disruption is not "AI writes code faster". Customers no longer need the software at all (e.g. no wiki needed if an agent answers directly).
- Agent outcomes = LLM + data. Tools and data access flip AI from building tools to delivering outcomes.
- Anecdote: a C-suite asset manager had Claude Code plus Daloopa data rebuild a financial terminal, then realised he would rather get a finished model and deck from one sentence.
- Assume anything someone does with AI can be done in 5 minutes. Pay for tokens and for data an LLM cannot get; the rest is free.
