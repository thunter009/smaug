Author claims to run Cowork as a full operating system and ranks 60 features by difficulty.

## Key Takeaways
- Top three: /plan before multi-file tasks, a custom Skills folder (SKILL.md), a daily 7am inbox triage via /schedule
- Slash commands: /schedule, /loop, /plan, /compact, /clear, /resume, /rename, /cost, /memory, /doctor, /voice, /agents
- Skills load on demand so they do not eat context; brand-voice skill built from 5-10 sample articles
- Sub-agents (/agents) give project-specific specialists like a PR reviewer or test writer
