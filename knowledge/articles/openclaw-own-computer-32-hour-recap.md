Recap of running OpenClaw for 32 hours on a dedicated spare Ubuntu laptop with fresh email, GitHub and X accounts, fully separated from the author's personal setup. Argues the work environment matters more than the machine.

## Key Takeaways

- Treat the agent like a new hire: own computer and accounts, no access to personal files, email or browser sessions.
- Share work through a GitHub repo (shared_workspace) that is version-controlled and reviewable.
- The agent organizes its own folders (writing/, x_metrics/, outbound/, project_ideas/) and keeps a recovery kit to rebuild the setup.
- Give it a full identity (name, personality, rules, language settings, memory files) for predictable behavior.
