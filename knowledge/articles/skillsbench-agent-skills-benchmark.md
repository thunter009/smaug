SkillsBench is an open-source benchmark measuring whether procedural "Skills" improve LLM agent performance. Built by 41 co-authors and 105 contributors; the launch post is the paper-v1 snapshot, and the registry has since grown to 87 native task packages.

## Key Takeaways

- 2-3 focused Skills give +18.6pp; 4+ Skills only +5.9pp; comprehensive docs -2.9pp
- Skills substitute for model scale: Haiku 4.5 with Skills (27.7%) beats Opus 4.5 without (22.0%)
- Less is more: focused procedural knowledge beats bulk documentation
