Describes a custom NextJS plus Convex app, generated by OpenClaw itself, that tracks agent work and improves proactivity and memory, with a copyable prompt for each screen.

## Key Takeaways

- Tasks board shows what agent and human each work on.
- Content pipeline moves ideas to script, thumbnail, filming.
- Calendar confirms scheduled tasks and cron jobs exist.
- Memory screen with global search; Team and Office screens organize and visualize sub-agents.
