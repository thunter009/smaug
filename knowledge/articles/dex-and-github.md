David Cramer explains how Dex, his simple agent-friendly task manager, syncs with GitHub issues without replacing GitHub as the tracker.

## Key Takeaways

- Root tasks (epics) auto-sync to GitHub issues; children embedded inside the issue body to avoid one-line subtask clutter
- Task metadata is encoded in the issue so Dex can restore it locally on import
- `dex import` pulls an issue into local tracking; LLM skills can break it into subtasks
- Sync is opt-in; remote issues only close once work is actually pushed to main
- Dex 0.2.0 shipped alongside
