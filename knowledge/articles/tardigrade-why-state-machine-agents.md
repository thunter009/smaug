Tardigrade docs on building long-horizon agents as actors with state-machine semantics, where behavior is easier to reason about.

## Key Takeaways

- Long-horizon agents branch into ever more trajectories; harnesses grow complex
- Author each agent as a state machine with transitions and side effects as pure functions of state
- Authoring agents resembles authoring frontend apps
