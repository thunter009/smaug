Article co-written with an OpenClaw agent describing VidClaw, an open-source self-hosted dashboard the agent built to manage itself.

## Key Takeaways

- Six panels: self-executing kanban, usage tracking, model switching, skills manager, soul editor with version history
- Localhost-only, accessed via SSH tunnel; no accounts or cloud
- Agent wrote the code; human drove UX and product decisions
