autocontext runs an agent on a task repeatedly while a multi-agent team analyzes each run and updates a shared knowledge base, so the next run inherits lessons. It targets agents lacking persistent memory across runs and context compaction.

## Key Takeaways

- Roles: Competitor, Translator, Analyst, Coach, Architect, Curator, sequenced by an Orchestrator
- Generations are gated by tournament matches or LLM judges with Elo-based progression; non-improving strategies roll back
- Knowledge persists only when validated, making it closed-loop optimization rather than prompt tweaking
- Problem framed as harness engineering: cold-start agents repeat mistakes
