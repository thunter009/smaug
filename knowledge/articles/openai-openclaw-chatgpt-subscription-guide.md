Guide to running OpenClaw on a ChatGPT subscription via Codex OAuth, avoiding API fees, after Anthropic's legal/compliance doc barred using Claude subscription credentials in third-party tools.

## Key Takeaways

- Claude subscription accounts are not allowed in tools like OpenClaw; OpenAI explicitly allows it
- Setup: `openclaw onboard --auth-choice openai-codex` selects ChatGPT OAuth
- Walkthrough video by Caleb Hodges, who does concierge OpenClaw setups
