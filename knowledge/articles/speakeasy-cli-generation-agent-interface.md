Speakeasy now generates production-grade Go CLIs from OpenAPI specs, with built-in agent mode, interactive TUI and cross-platform distribution (beta).

## Key Takeaways

- Thesis: MCP suits non-technical users in shell-less environments; coding agents live in terminals, so CLIs are their native interface.
- Agent mode auto-detects agent callers, switches to structured output, disables interactivity.
- Humans get a full TUI from the same CLI: one spec, two audiences, no drift.
