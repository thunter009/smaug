Walkthrough of building a small TUI app (multi-timezone hourly table with a local-LLM command bar) from a blank directory in Claude Code, using the author's shaping skills to separate problem from solution before coding.

## Key Takeaways

- Invoke the shaping skill on the first prompt: it captures requirements ("R" items) and candidate solutions ("Shape A", parts A1..A6) in a shaping.md doc.
- Claude's first draft is imperfect (some R items are really solution details); iterate on requirements and shape separately.
- Solution options A, B, C get compared before choosing; terminology comes from the skill.
- A Markdown previewer with hot reload makes the shaping doc a live artifact.
- Captured text is truncated; the full article is on X.
