Clearly is a free, open-source native markdown editor for Mac and iPhone. Its April 8, 2026 update turns it into a document workspace with folders. Any folder reachable in Finder can be added as a location, so it works on existing document directories.

## Key Takeaways

- Native markdown editor for Mac and iPhone, free and open source
- Write with syntax highlighting, then toggle to a rendered preview
- New folder-based document workspace uses existing file locations; no import or move step
- Landing page lists v3.3.0 and requires macOS Sequoia or later (page version may be newer than the April update)
