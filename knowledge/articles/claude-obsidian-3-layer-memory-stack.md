Walkthrough of a 3-layer compounding memory stack for Claude Code: CLAUDE.md plus auto-memory, an Obsidian knowledge graph over MCP, and ingestion of external research. Claims ~85% less context-rebuilding time.

## Key Takeaways

- "Context Amnesia" costs 30-40 min per session re-explaining context; bigger context windows are not the fix.
- Layer 1: CLAUDE.md (nouns, verbs, boundaries) bootstrapped via /init, plus auto-memory MEMORY.md.
- Layer 2: Obsidian vault via MCP (Smart-Connections semantic search, QMD hybrid search).
- Layer 3: ingest YouTube/PDF into the vault with a local transcribe+extract tool, auto-wikilinked.
- A "Polaris" Top Mind note holds goals and principles so Claude can flag misaligned decisions.
