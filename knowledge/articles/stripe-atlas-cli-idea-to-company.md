# Go from idea to company with Stripe Atlas in the CLI

Stripe blog post: Atlas lets you incorporate a company with the same tools used to build the product, in the CLI. @stevekaliski frames the Stripe MCP server and CLI as a "business factory" for agents.

## Key Takeaways
- Agent can form a company via Atlas, build a payments integration, manage funds in Treasury, handle support inquiries, monitor business performance
- MCP server at mcp.stripe.com requires a Stripe API key (unauthenticated returns missing_api_key)
