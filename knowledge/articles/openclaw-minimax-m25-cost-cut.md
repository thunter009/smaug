Walkthrough of running OpenClaw on MiniMax M2.5 instead of Opus 4.6 for roughly 95% lower cost, with install, model, OAuth and Telegram bot setup steps.

## Key Takeaways

- MiniMax M2.5: 80.2% SWE-Bench Verified (on par with Opus 4.6), 76.3% BrowseComp, 76.8% BFCL tool calling
- Built for long-horizon agentic workflows
- MiniMax Coding Plan starts at $8.8/month
- Setup: install OpenClaw via openclaw.ai script, pick MiniMax M2.5, set OAuth/API key, register Telegram bot via BotFather
