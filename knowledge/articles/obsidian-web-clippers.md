# Ten Obsidian Web Clipper Templates You're Probably Not Using

X article by @KanikaBK with ten Obsidian Web Clipper templates, from a clean-save default to a local-model setup. Each template includes paste-ready code. Author estimates about 5 minutes saved per clipped page.

## Key Takeaways
- Web Clipper fills a template from page variables such as {{title}} and {{url}}
- Interpreter sends each {{"quoted prompt"}} to an AI model and inserts the answer
- Keeper: default clean-save template with source, author, published, and clipped properties
- Skim: 3-bullet AI summary plus full text. Marker: saves only highlighted lines
- Switchboard: triggers pick a template by URL or schema.org type. First match wins; first template in list is the fallback
- Chef (schema:@Recipe), Reader (papers, status to-read), Tester (product pages, manual verdict), Scout (appends leads to one note)
- Miner: Interpreter context that turns pages into post hooks. Vault: local model through Ollama for privacy
- Trade-offs: fiddly setup, API cost per clip unless local, small models err on numbers and paywalled pages
