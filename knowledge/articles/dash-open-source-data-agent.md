Ashpreet Bedi open-sources Dash, a self-learning text-to-SQL data agent modeled on OpenAI's internal data agent. It grounds answers in six layers of context and learns from errors without fine-tuning.

## Key Takeaways

- Six context layers: table usage, human annotations, query patterns, institutional knowledge, memory, runtime schema
- Hybrid search retrieves context at runtime
- Self-learning via static knowledge plus an agentic LearningMachine (no GPUs needed)
- Repo: https://github.com/agno-agi/dash
