ClaudeKit, featured on Claude Code Templates (aitmpl), packages agents and skills into a command pipeline for spec-driven development with TDD baked in, working through phases with progressive disclosure to keep context small.

## Key Takeaways
- /docs:init scans the codebase and generates specs
- /brainstorm interrogates you until requirements are solid
- /plan produces a phased implementation plan
- /clear resets context so the plan drives clean output
- /code:auto implements phase by phase using progressive disclosure
