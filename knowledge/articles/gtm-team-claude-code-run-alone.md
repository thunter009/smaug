Argues a GTM team is mostly judgment (who to message, what proves you noticed, which no-show to chase), and one person plus Claude Code can run it end to end. Builds the team seat by seat, each with a Claude Code prompt.

## Key Takeaways

- Think in jobs, not headcount; sending is cheap, judgment is the hard part.
- Prospector seat watches four signals: role opens/reposts, competitor engagement or problem posts, launches/stack changes, funding/acquisitions.
- Drafts must quote the trigger that moved; if a message could have gone out unchanged last month, skip the account.
- Researcher seat writes a one-page brief for each booked call from shared memory (trigger, history, opener).
- All seats share one memory; the human edits rather than operates.
