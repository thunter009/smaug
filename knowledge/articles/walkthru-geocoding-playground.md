Browser-based geocoder powered by DuckDB-WASM that searches Overture Maps address data straight from Parquet files, with no backend or API key. The 2026-04-15 Overture release adds 472M addresses across 39 countries, hosted via Source Cooperative.

## Key Takeaways

- Serverless geocoding: DuckDB-WASM queries remote Parquet in the browser
- Covers forward and reverse geocoding on open Overture address data
- Free, no install, no API key
